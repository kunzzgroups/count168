输入属性对照 / Input attribute matrix

目的：找出让输入法不把字留在自己的组合缓冲区的那组 input 属性 —— 用户症状是 “连按删除 6 次才开始删”，而这几次删除很可能被输入法内部消化了。
Goal: find the input attributes that stop the keyboard from holding the text in its own composition buffer.

  1. 在每个框里用同一个输入法输入 abcde（英文键盘）。
  2. 连按删除 6 次，看下面的数字变化。
  3. 找「删除立刻生效」且「真正缩短输入框 = 删除事件数」的那个框，把编号（A–H）告诉客服。
读法：「真正缩短输入框」少于「删除事件」＝那几次删除只改动了输入法的组合缓冲，输入框内容没变； 「首个事件延迟」很大或「补发批次」> 0＝事件被攒起来一次性送达。
